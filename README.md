# Flappy Bird Game - Java OOP Project
A Java-based implementation of the classic Flappy Bird game developed using **Object-Oriented Programming (OOP)** principles. This project includes a graphical user interface built with Swing, user authentication, and score tracking via Microsoft Access database integration.

## 🎮 Features
- Classic Flappy Bird gameplay with smooth bird controls and collision detection
- User Authentication System (Login & Sign-Up) with database integration
- High Score Tracking stored in Microsoft Access
- Object-Oriented Design using Inheritance, Polymorphism, Encapsulation, and Abstraction
- Interactive GUI with start/restart functionality and real-time score display
- Design Patterns implementation (Proxy Pattern for image loading)

## 🛠️ Technologies Used
- Java (JDK)
- Swing (GUI)
- JDBC (Database Connectivity)
- Microsoft Access (Database)
- NetBeans IDE (Development)

## 🚀 How to Run
### Prerequisites:
1. Install **Java JDK 8+**
2. Install **Microsoft Access** (for database)
3. Set up JDBC-ODBC bridge (if needed for older Java versions)

### Steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/flappy-bird-java.git
   ```
2. Open the project in **NetBeans** or your preferred Java IDE.
3. Ensure the database file path is correctly set in the database connection code.
4. Run `Game.java` as the main class.
5. Use the login/sign-up screen to authenticate.
6. Press **ENTER** to start the game.
7. Press **SPACEBAR** to make the bird jump.

## 🎯 Game Controls
- **SPACEBAR**: Make bird jump
- **ENTER**: Start/Restart game
- **Mouse Click**: Navigate menus & buttons
